# Beta people, centered weather and expandable globe

Beta remains at `/weather-fusion/v3/`, publicly accessible through the main app’s Try Beta link. The prominent Main app return button is preserved. The main app’s interface and weather engine are unchanged by this update. Existing sky, moon, sunset, model-comparison, ranking and ice-frame changes from main were integrated before final validation.

The location is now plain centered text within the hero and still opens search. The date, temperature, current condition, feels-like and high/low are centered. Branding uses the existing transparent SVG icon with live HTML lettering, without a rectangular raster badge. Header, menu and chart controls use glass styling. Fahrenheit/Celsius remains accessible in the tools menu.

Shade, Day/Sun/Rain/Night and For Pets appear as three compact illustrated cards. Titles, square scenes, readings and descriptions follow their natural content height; no fixed blank header or reading bands remain. On wider screens the scenes sit beside their readings. They reuse the main app’s condition-specific artwork and clothing helpers, including genuine night scenes. The outdoor night reading uses the existing outdoor feels-like value, rather than a missing sunlight value. Pet cards still expand to show both surfaces and peaks for the selected local calendar day; the existing thermal solver and weather formulas are unchanged. The latest main-branch future-preview heading behavior is retained.

The globe preview expands into a keyboard- and touch-operable native dialog. It supports drag rotation, pinch/buttons/wheel zoom, geographic recenter, independent satellite/radar/wind toggles, observed radar playback and browser Back. One WebGL renderer moves between preview and expanded views. The fixed 9px marker uses the exact selected forecast coordinates and stays the same screen size at every zoom. Satellite/street basemaps load finer geographic tiles through city and street scale, with place labels and a basemap toggle. The preserved detailed local radar remains accessible, and now sends `latitude`/`longitude` rather than the previously incorrect `lat`/`lon` names.

Data and limitations:

- MapLibre GL JS 5.6.2 is vendored with its BSD license. Its globe projection renders Esri imagery/labels or OpenStreetMap streets, with attribution. Existing Three.js/base textures remain available for older open clients but are no longer loaded by the new Beta. This does not change the separate Next Gen checkout.
- Clouds use the timestamped global infrared satellite composite from UW–Madison SSEC RealEarth. The source is projected correctly from Mercator onto the globe. Bright IR areas can include cold ground; this is disclosed beside the controls. No stock cloud fallback is displayed.
- Radar uses only real advertised, recent NOAA MRMS reflectivity frames, projected over the continental-US coverage area. This layer does not claim worldwide radar coverage.
- Surface winds primarily use NOAA GFS east/north vectors from PacIOOS ERDDAP (the current destination of NOAA CoastWatch’s redirect): 5° global sampling plus native 0.5° regional fields for the selected/viewed 10° region. Actual three-hour valid times are displayed. Global and regional request caches deduplicate visitors. The existing hourly Open-Meteo GFS field remains a fallback. Recent last-known real winds can remain visible with an update-delayed label for at most four hours. Missing cells stay missing; regional fields do not wrap across their edges. Stronger winds create more/faster streamlines; paused motion shows directional arrows. Motion is accelerated for readability, not a storm trajectory.
- Weather layers have visible timestamps and honest unavailable states. Wind is cached once per UTC hour, cloud metadata for 10 minutes and radar metadata for 2 minutes. Weather tiles are georeferenced in Web Mercator. Observed satellite brightness drives cloud transparency; its opacity fades at close zoom to keep streets visible. Radar keeps up to 13 advertised frames from the last two hours. Previously advertised times remain usable for three hours so metadata refresh cannot invalidate the selected frame. Tile buffers are bounded to 160 entries/8 MiB; regional fields are bounded as well. New tile layers double-buffer and discard stale asynchronous loads during rapid scrubbing. Concurrent requests deduplicate, failed sources cool down and provider retry windows are respected.
- Layer metadata refreshes every two minutes while visible, with a manual Refresh layers control. Unchanged wind and image timestamps reuse existing GPU resources; all polling stops when hidden/offscreen, and Save Data suppresses automatic preview polling. Globe assets and feeds load after weather is available and the preview approaches the viewport, or upon explicit expansion. Animation pauses offscreen/when hidden. Reduced-motion and Save Data start without automatic motion, and Save Data defers automatic globe loading. Rendering caps pixel ratio and wind particles. WebGL failure leaves detailed local radar accessible.
