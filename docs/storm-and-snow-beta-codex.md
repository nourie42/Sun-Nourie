## Screen contract
- Storm and Snow Beta is the existing Snow Outlook launcher; keep both centers independently accessible regardless of weather.
- Each center: header/location/back; Today (Remainder of Today after noon), 1–3 days, 3–5 days, with explicit valid times; hero expected amount, chance, event timing, trend, confidence, update time; large clickable regional accumulation map preview; 2-column grid of Chance & Amounts, Forecast Changes, Storm Timing, Live Tracking, Forecast Confidence, Weather Impacts.
- Each click opens a dedicated detail screen, preserving location, period, event and back navigation. Mobile map fills most of screen; desktop layer panel left, map center, summary right. 44px targets, no horizontal overflow, keyboard and screen-reader support.
- Map: real regional forecast overlay, selected location, pan/zoom/recenter, legends, period/layer selectors, clicked-point popup, highest totals from coherent spatial regions, prior/current difference. Rain layers: total/observed/remaining, lower/upper, probability, threshold exceedance, rain rate, radar, flood outlook. Snow: corresponding snow layers plus precipitation type and ice. Distinguish valid times; do not label a different period's map as the selected forecast.
- Probabilities: rain measurable >=0.01", thresholds .10/.25/.50/1/2/3/5"; snow measurable >=.1", thresholds 1/2/4/6/8/12". Separate occurrence from accumulation; exceedances monotone, exclusive bins sum to 100%; no fabricated values or deterministic-to-probability shortcuts. Present P50, P25–P75 expected range, P10/P90 scenarios only from calibrated distributions. Do not call P50 a mode.
- Changes: immutable snapshots for equivalent storm/location/window; compare previous, 3/6/12/24/48h and original; previous/current amount & probability, graph with uncertainty bands, data-grounded explanation, update time. Use configurable material-change thresholds (.25" rain, .5" snow, 10 percentage points, 2h, material track/type change). Avoid claiming certainty or directional trend without history.
- Timing: broad time windows at long range; hourly rates, onset/peak/end and dry windows only if supported. Live: radar and verified precipitation type, observed vs remaining amounts; never infer snow depth from radar. Confidence: calibrated occurrence, amount, timing, placement and type, transparent coverage. Impacts: official NWS watches/warnings and WPC outlooks separately from modeled risks.

## Forecast methodology
Audit existing rain and snow blends before modifying; keep operational rules unchanged outside this beta. Independently evaluate compatible guidance for each lead-time band. 3–5 days: ECMWF IFS ENS, GEFS, NBM, WPC QPF for rain and extended winter outlook for snow; Canadian ensemble, AIFS/WeatherNext only if variables/coverage verified. 1–3 days: WPC probabilistic QPF/PWPF, NBM, ensembles, regional guidance if eligible; same day HRRR/NBM/WPC/NWS and eligible regional ensembles; near-real-time radar/MRMS and gauges for rain, verified snowfall and precipitation-type observations for snow. Confirm current NBM version and published fields. Never equate extended-range winter liquid equivalent with snow depth. WPC/NBM share model inputs; avoid double-counting. HRRR deterministic amounts aren't probabilities. Evaluate current blend against candidate weights rather than claiming universal optimal weights. Consider model coverage, freshness, exact interval, units, regional bias, thermal profiles, snow ratios, melting, cold-air damming, convection/training and local rain/snow boundaries. Use compatible fields, calibrated probability distributions, smooth lead transitions, robust fallbacks and explicit unavailable states. Update only for new source cycles or meaningful observations; poll 60 min extended, 30 min near-term, 15 min same-day, 2–5 min active observations where allowed. Maintain cycle/issue/valid/retrieval timestamps. Forecast map and local tiles must use same versioned snapshot; separate official maps when periods differ.

## Validation
Backtest rain and snow separately at 120/96/72/48/24/12/6/3/1h against verified observations, including dry/false alarm cases; MAE, RMSE, bias, Brier score, reliability, CRPS, timing and spatial skill. Use independent storms and holdout sets, versioned weight updates with rollback. Never fabricate probabilities or silently substitute zero. Test unavailable/stale inputs, all precipitation types, unit conversions, probability consistency, map period alignment, navigation/back, accessibility, no duplicate accumulation, changing locations, DST, mobile layouts, network/timeout and all existing regressions. Report actual test results and limitations. Present preview screenshots and draft changes for approval; do not merge or deploy.
