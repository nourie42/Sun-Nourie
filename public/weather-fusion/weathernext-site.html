Everything Google publishes for forecasting

The dashboard retains all 21 surface and station-trained fields in the field catalog, with the mean and P10, P25, P50, P75 and P90 statistics when supplied. Main forecasts can extend to 360 hours; interim forecasts extend to 48 hours. Runs remain separate and missing values stay missing.

Station-trained temperature and dew point are separate model outputs, not live station observations. Station and surface run timestamps are displayed independently. The hero, daily outlook, scene and detail tiles use surface ensemble means; choosing a station-trained variable changes the explorer, not the source of the overview.

0.05° station-trained output provides temperature and dew point. 0.1° gridded surface output provides the surface fields. The 0.25° 3D atmosphere spans 13 levels and is available through the separate Cloud Storage product.

Raw 64-member trajectories, pressure-level atmospheric fields and native six-hour accumulation products are separate Google Cloud Storage products. They are not reconstructed from percentiles here.

Scene labels are display categories derived from mean cloud cover and precipitation, not Google-issued condition codes. The daylight illustration uses an approximate astronomical calculation for the selected point and time. No thunderstorm, snow, UV, air quality, live radar, wind gust or calibrated rain-probability value is invented.

Precipitation means from the model-native, IMERG-trained and satellite-radar-trained fields are alternative model outputs; they are not additive. Solar radiation is not UV index. Hourly values and the exact coverage of the downloaded run remain available even when the default day list is shortened.
